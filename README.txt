HISAB KITAB — Version 2.0

Upload these three files together to the same folder on Netlify or GitHub Pages:
- index.html
- manifest.json
- sw.js

Then open the HTTPS website in Chrome on Android and choose:
Chrome menu > Install app / Add to Home screen.

Important:
- App starts with ZERO accounts and ZERO transactions.
- Create an account for each customer/work location using “Create new account”.
- Each account has its own motor types and daily entries.
- Add motor types under Settings after selecting an account.
- Data is saved locally in the browser on this device. There is no automatic cloud sync in this version.
- Use Settings > Backup data regularly. Restore the JSON backup on the same app if needed.
- Offline use is available after the app has been opened online once and the service worker has cached it.
